# Tic Tac Toe: Bomb Defusal

Terminal tic tac toe, Python standard library only. Each player's turn is
timed by a live fuse bar; three in a row wins, a full board draws, STOP
quits anytime. Solo build — see `PLAN.md` for full status and design notes,
`QUEUE.md` for what's left before the deadline.

## Run it

```
python3 tic_tac_toe.py
```

or, since it's executable:

```
./tic_tac_toe.py
```

Any Python 3 works. Nothing to install.
